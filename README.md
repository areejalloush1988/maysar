# ميسر | Maysar

نسخة أولى لتطبيق وساطة تمويلية للشركات، بالعربية والإنجليزية. العربية من اليمين إلى اليسار. الإصدار 2.0.0، بتاريخ 17 نوفمبر 2026.

## التجربة الآن

افتح `Maysar-App.html` في متصفح حديث، واختر **استكشف التطبيق** ثم **املأ مثالًا للتجربة**. البيانات تحفظ في المتصفح نفسه، والملفات تحفظ في IndexedDB. استخدم بيانات تجريبية؛ حذف بيانات المتصفح يحذف هذه التجربة. بعض عارضات الملفات على الهاتف لا تشغّل JavaScript؛ استخدم متصفحًا أو النسخة المستضافة.

الرحلة المتاحة: تقييم من 7 خطوات، ملف الشركة، رفع وتنزيل مستندات PDF/PNG/JPEG حتى 10 ميغابايت، تقرير أولي قابل لتنزيل PDF، طلب مراجعة وموافقة مشاركة، سجل الحالات، رسائل مرتبطة بالطلب، إدخال عروض من لوحة الوساطة، مقارنة حتى 3 عروض، وتسجيل اختيار العميل.

رابط «مساحة فريق الوساطة» متاح في التجربة فقط. الحساب الحقيقي يعتمد دورًا محفوظًا في قاعدة البيانات؛ تعديل بيانات الحساب في المتصفح لا يمنح صلاحية خادم.

لا توجد دفعات فعلية أو إيداعات أو إرسال آلي إلى ممول. لا توجد شراكات مفترضة مع الجهات المدرجة. نتائج المطابقة تختبر شروطًا معلنة محدودة، ولا تحسب احتمال الموافقة أو مبلغًا يضمن البنك منحه. اكتمال الملف مقياس للبيانات والمرفقات فقط. التقرير يحفظ نسخة من المعايير وقت الإصدار. PDF مرسوم للحفاظ على العربية؛ النص داخله غير قابل للبحث.

## التشغيل والبناء

يلزم Node.js 24. لا يحتاج التطبيق إلى تثبيت مكتبات JavaScript.

```sh
npm test
npm run build
```

ينشأ مجلد `dist` للنشر وملف `artifacts/Maysar-App.html` المستقل. ملف `app-v2.html` هو مدخل المصدر. الشفرة القديمة أزيلت من هذه الحزمة.

## تفعيل الحسابات والحفظ عبر الإنترنت

1. اختر مشروع Supabase جديدًا مخصصًا لميسر داخل حساب المالك. لا تشغّل مخطط البيانات على تطبيق قائم آخر.
2. شغّل `backend/schema.sql` مرة واحدة من SQL Editor. ينشئ الملفات الشخصية، الشركات، الطلبات، الموافقات، الأحداث، الرسائل، العروض، الاختيارات، التقارير ودليل الجهات، مع RLS وحاوية مستندات خاصة.
3. ضع عنوان المشروع والمفتاح **publishable** في `config.js`. لا تضع مفتاح secret أو service_role في هذا الملف أو GitHub.
4. اضبط عنوان الموقع النهائي والتحويلات المسموحة في إعدادات Auth. فعّل تأكيد البريد واضبط بريد الإرسال قبل استقبال العملاء. رابط استعادة الحساب الحالي يرسل طلب الاستعادة؛ إتمام تغيير كلمة المرور يحتاج صفحة استعادة مخصصة قبل الإطلاق العام.
5. أنشئ حساب المسؤول عبر التسجيل العادي، وتأكد من UUID الخاص به، ثم نفّذ من SQL Editor بصلاحية المالك:

```sql
update public.profiles set role = 'admin' where id = 'CONFIRMED-USER-UUID';
```

لم يُنشأ مشروع قاعدة بيانات أو يُطبّق هذا المخطط على حساب فعلي ضمن تسليم هذه الحزمة. اختبارات RLS بين حساب عميل A وعميل B ومستشار ومسؤول مطلوبة بعد الربط؛ اختبارات الشفرة المحلية لا تثبت صلاحيات قاعدة منشورة.

الانتقالات محكومة بالخادم: الإرسال يحتاج مرجعًا وموافقة على جهة محددة، إضافة العرض تحتاج طلبًا مرسلًا، مرحلة العروض تحتاج عرضًا مسجلًا، التعاقد يحتاج اختيار العميل، وتأكيد الصرف يحتاج مرجعًا. الحالة لا تُحدّث تلقائيًا من أي ممول. العروض المسجلة في حساب حقيقي يجب أن تعكس مستندًا فعليًا لدى الفريق.

## النشر على رابط خارجي

للتطبيق مستودع مستقل: https://github.com/areejalloush1988/maysar . النشر الحالي يقدّم الملف المستقل `index.html` من فرع `main` وجذر المستودع على GitHub Pages. يحتوي `maysar-source.zip` على مصدر التطوير المنظّم والخطوط والأيقونات والاختبارات ومخطط قاعدة البيانات. بعد استخراج المصدر داخل مستودع تطوير، يمكن تفعيل النشر بالبناء الآلي عبر `.github/workflows/pages.yml` بدل النشر المباشر؛ الملف يختبر ويبني وينشر مجلد `dist`. ويمكن نقل محتويات `dist` إلى استضافة المالك وربط نطاقه. مستودعات Varex وAhed منفصلة عن هذا التطبيق.

النشر الحالي يعرض تجربة محلية داخل المتصفح، مع عدم تفعيل الخدمات السحابية أو تحصيل أموال. لتحديث النسخة المنشورة بعد تعديل المصدر أو الإعدادات، نفّذ البناء واستبدل `index.html` بالملف المستقل الناتج، وحدّث أرشيف المصدر معه. لا يوجد اعتماد على روابط معاينة أو هوية ChatGPT داخل واجهة التطبيق. ملف `.openai/hosting.json` إعداد اختبار محلي مستبعد من المستودع الخارجي.

## قبل استقبال طلبات فعلية

تحتاج سياسات الخصوصية والشروط اسم الشركة المشغلة ووسيلة التواصل ورسوم الخدمة الفعلية. يلزم تحديد شروط الخدمة وموافقة الممولين ومسار تسليم المستندات، وتفعيل الدفع عبر تكامل خادم مع إشعارات دفع موثقة إذا اعتمدت رسومًا. لا يتم تحصيل أي رسوم بمجرد تغيير `paymentsEnabled`؛ لا يوجد تكامل دفع في الإصدار الحالي. التحقق من بصمة الملف ليس فحص فيروسات.

الرسائل تتحدّث عند إعادة تحميل الصفحة أو اختيار «تحديث البيانات» من الإعدادات؛ لا يوجد بث فوري أو إشعارات خارجية. مستندات الشركة مرتبطة بملف العميل الحالي؛ أرشفة نسخة مستندات ثابتة لكل طلب مطلوبة قبل اعتماد مشاركة رسمية. لا يوجد ربط بنكي أو استعلام ائتماني أو توقيع عقد إلكتروني في هذا الإصدار.

## English

Maysar v2 is a bilingual business-finance brokerage starter with a dedicated GitHub repository and a static Pages deployment. The published root `index.html` is self-contained. `maysar-source.zip` preserves the structured source and tests. Use the local demo with test information, generate a PDF, create a consented internal review, switch to the demo broker workspace, record status changes and messages, enter sample offers and compare them as the client. No production database, payment processor or provider integration has been activated. `backend/schema.sql` is prepared for a new Supabase project and requires live security verification after installation.
